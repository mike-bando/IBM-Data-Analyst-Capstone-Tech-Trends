# IBM Data Analyst Capstone Project: Tech Trends Analysis

## Project Overview
This project is the culmination of the IBM Data Analyst Professional Certificate. The goal is to analyze the current technology landscape for software developers, identifying the most in-demand programming languages, databases, and emerging technologies.



## Methodology
The project follows a full data analysis life cycle:
1. **Data Collection:** Web scraping using BeautifulSoup and data retrieval via APIs.
2. **Data Wrangling:** Cleaning and pre-processing dirty data using Pandas.
3. **Exploratory Data Analysis (EDA):** Analyzing trends and distributions using SQL and Pandas.
4. **Data Visualization:** Creating professional visuals using Matplotlib, Seaborn, and Plotly.
5. **Interactive Dashboard:** Building a dynamic dashboard using Dash to showcase findings.

## Technologies Used
* **Languages:** Python (Pandas, BeautifulSoup, Plotly, Dash)
* **Database:** SQL (SQLite / IBM Db2)
* **Tools:** Jupyter Notebooks, VS Code, Git/GitHub

## Project Structure
- `/data`: Raw and processed datasets.
- `/notebooks`: Detailed Jupyter Notebooks for each stage of the analysis.
- `/dashboard`: Python scripts for the interactive Dash application.
